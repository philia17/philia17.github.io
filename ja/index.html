01

ロボティクスと認識

ロボットによるエレベーター操作

ロボットがエレベーターを
読み取るには。

ボタンを認識した後は、目的のボタンを選び、3次元位置を特定して、安全に近づく必要があります。このプロジェクトでは、各段階に安全対策を組み込んだ処理フローでそれらをつなぎます。

RGB-D · OpenCV · キャリブレーション · ロボットアーム

担当した内容 — 共同研究での段階的な認識、RGB-Dによる位置推定、キャリブレーション、安全対策を組み込んだアームの統合。

プロジェクトノートを開く +

ボタン検出、HOG+SVMによる分類、意味に基づく対象選択、RGB-Dによる位置推定、キャリブレーション、安全対策を組み込んだロボットアーム操作を一連の処理にまとめています。

評価結果 — ラベル付きのボタン切り出し画像379枚でマクロF1は0.9963、オフラインでのリクエスト単位の対象選択精度は85.1%でした。定性的な実演2件は、さまざまな環境での運用を裏付ける検証とは区別しています。

02

エッジAI

Raspberry Pi 5 工学学習アシスタント

小さなコンピューターで、
根拠をたどれる回答を。

小型言語モデルに、授業資料の検索と計算ツールを組み合わせました。回答を生成した根拠を、その場で確認できることが目標です。

Python · Qwen3-1.7B · RAG · Raspberry Pi 5

担当した内容 — 量子化モデルの実装、検索・計算ツール、処理の根拠を確認できるWebインターフェース、構成間の比較。

プロジェクトノートを開く +

4ビット量子化したQwen3-1.7Bに資料検索と決定論的な計算ツールを組み合わせています。Webプロトタイプでは、生成した回答、検索した資料、ツール出力を区別して表示します。

評価結果 — 電気電子工学の96問を用いて、GPUによるオフラインの基準評価で7構成を比較しました。Pi 5のCPUでの観察結果は同じ量子化モデルを使った別評価です。基準評価の得点はGPUで得たものです。

03

人とロボットのインタラクション

Bangbang V2

最終判断は
人が行う。

アバターロボットの遠隔操作を支援する表情認識と2言語の音声認識です。オペレーターが最終判断を行う構成で、Raspberry Pi 5上の画像認識経路を開発しました。

MediaPipe · ONNX · エッジ画像認識 · 遠隔操作

担当した内容 — 共同開発した遠隔操作システムの表情認識パイプラインと、Pi 5上の画像認識の統合。

プロジェクトノートを開く +

2台のPiによる遠隔操作システムは、MediaPipe FaceMeshの前処理、相互補完的なCNNと解釈可能なFACS/AUによる認識、2言語の音声認識、ブラウザー上のインターフェースを組み合わせています。

AIの出力は判断の参考情報です。最終判断の責任はオペレーターが負います。

共通プラットフォームを対象にした学会論文は2本あります。表情認識と2言語の音声認識を扱うHRFESTの論文230と、人が判断に関与するエッジ／クラウドLLMによる意思決定支援を扱うIHCIの論文99です。

03 / プロフィール

システム全体を
見渡す力を養う。

葉嗣恒 / Siheng Ye

電気電子工学を出発点に、ロボティクス、制御、機械のすぐそばで動かせるAIへと関心を広げています。

ノッティンガム大学寧波校でBEng (Hons)課程を履修しており、2027年7月に卒業予定です。組み込みシステム、制御と自動化、サイバーフィジカルシステム、エッジAIの分野で大学院進学を準備しています。

卒業研究では、PMSMの予測トルク制御におけるデジタル遅延補償と予測のロバスト性をシミュレーションで検討しています。探索段階の研究で、実機検証は今後の課題です。

どのプロジェクトでも、何を測定できるか、何を説明できるか、人がどこで制御を担うべきかを大切にしています。

ことばと世界を探る。 工学のほかに、読書、語学、旅行を楽しんでいます。

組み込みシステム、ロボティクス、制御、電子機器の試験、応用AIの分野でインターンシップを探しています。学期中は授業に合わせた時間帯で、UNNC周辺への週2～3回の出勤を相談できます。
