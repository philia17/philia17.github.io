01

ロボティクス・環境認識

ロボットによるエレベーター操作

エレベーターのパネルを
読み取るロボット。

ボタンを見つけたら、指示されたボタンを選び、3次元位置を特定して安全に近づきます。このプロジェクトでは、安全対策を組み込み、認識から操作までの流れを段階ごとに設計しました。

RGB-D · OpenCV · キャリブレーション · ロボットアーム

担当 — 共同研究で、段階的な認識処理、RGB-Dによる位置推定とキャリブレーション、安全対策を備えたロボットアームの統合を手がけました。

技術詳細と評価結果 +

ボタン検出、HOG+SVMによる分類、指示の意味に基づくボタン選択、RGB-Dによる位置推定、キャリブレーションを、安全対策を備えたアーム操作につなげています。

評価結果 — ラベル付きのボタン画像379枚でマクロF1は0.9963、オフラインで指示ごとに対象ボタンを選ぶ評価では正解率85.1%でした。実機での実演は定性的な確認2件に限られ、さまざまな環境での運用は未検証です。

02

エッジAI

Raspberry Pi 5 工学学習支援ツール

小型コンピューターで、
根拠をたどれる回答を。

小型言語モデルに、授業資料を検索する機能と計算ツールを組み合わせました。回答がどの資料や計算に基づくかを、利用者がその場で確かめられるようにします。

Python · Qwen3-1.7B · RAG · Raspberry Pi 5

担当 — 量子化モデルの導入、検索・計算ツールの組み込み、根拠を確認できるWeb画面の開発、システム構成の比較。

技術詳細と評価結果 +

4ビットに量子化したQwen3-1.7Bに、資料検索と決定論的な計算ツールを組み合わせています。試作したWeb画面では、生成した回答、参照資料、ツールの出力を分けて表示します。

評価結果 — 電気電子工学の96問を使い、GPU上のオフライン評価で7通りの構成を比較しました。Pi 5のCPUでも同じ量子化済みモデルを動かし、その結果はGPUの得点と分けて報告しています。

03

人とロボットのインタラクション

Bangbang V2

遠隔操作の最終判断は
人の手に。

アバターロボットの遠隔操作を、表情認識と2言語対応の音声認識で支援します。私はRaspberry Pi 5で動く画像認識部分を開発しました。最終判断はオペレーターが行います。

MediaPipe · ONNX · エッジ画像認識 · 遠隔操作

担当 — 共同開発した遠隔操作システムで、表情認識パイプラインの実装とPi 5への組み込みを担当しました。

技術詳細と評価結果 +

2台のPiで構成する遠隔操作システムです。MediaPipe FaceMeshで前処理し、CNNと、判断根拠を追いやすいFACS/AUによる認識を併用します。2言語対応の音声認識とブラウザーで操作できる画面も備えています。

AIは判断材料を提示し、最終判断はオペレーターが担います。

同じプラットフォームを題材にした学会論文は2本です。HRFESTの論文230では表情認識と2言語対応の音声認識を、IHCIの論文99ではエッジとクラウドのLLMを用いた、人による判断を支える仕組みを扱います。

03 / プロフィール

システム全体を
見る力を磨く。

葉嗣恒 / Siheng Ye

電気電子工学を出発点に、ロボティクス、制御、機械のすぐそばで動かせるAIへと関心を広げています。

ノッティンガム大学寧波校のBEng (Hons)課程に在籍し、2027年7月に卒業予定です。組み込みシステム、制御・自動化、サイバーフィジカルシステム、エッジAIをさらに学ぶため、大学院進学の準備を進めています。

卒業研究では、PMSM（永久磁石同期モーター）の予測トルク制御を対象に、デジタル制御の遅延補償と予測のロバスト性をシミュレーションで調べています。現在は探索段階で、実機での検証はこれからです。

何を測定し、結果をどう説明できるか。どこで人が判断や操作を担うべきか。こうした点をどのプロジェクトでも重視しています。

言葉を学び、世界を巡る。 工学以外では、読書や語学、旅行が好きです。

組み込みシステム、ロボティクス、制御、電子機器の評価、応用AIの分野でインターンシップを探しています。学期中は、UNNC周辺であれば授業時間に合わせ、週2～3回の出勤を相談できます。
