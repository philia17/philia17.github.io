項目概覽

小型語言模型即使回答流暢，也可能用錯資料或算錯數字。我們的原型把四位元 Qwen3-1.7B 模型、課程資料檢索與確定性計算工具結合，讓答案有可查閱的依據。

Ask 在答案旁顯示資料來源或計算過程；Quiz 則在使用者作答後，提供回饋及相關資料。平台以 Raspberry Pi 5 為目標裝置，各項元件與不同裝置的評估結果分別列出。

我的貢獻

我主導團隊中邊緣端原型的實作，整合檢索與計算工具，建立能查閱回答依據的 Ask／Quiz 流程，並比較不同系統配置。

評估結果與限制

主要測試在離線 GPU 環境中進行，以 96 道電氣與電子工程題目比較七種配置。下表列出依 0–1 評分標準計算的平均分數，以及達到完全正確標準的答案數。

配置平均評分完全正確

RAG 是檢索增強生成，SFT 是監督式微調。這裡的評分不是準確率百分比。Base + Tools 在 RAG 中加入工具：支援的計算交由確定性 Calculator 執行，其他請求則使用檢索。上方特別列出的 GPU Base + Tools 與 Pi Base（不查閱外部資料）採用不同配置，不能視為相同條件下的硬體比較。

另一次配對比較在兩種裝置上都使用不查閱外部資料的 Base、相同的量化模型檔案及 96 道題目。GPU 平均分數為 0.503，Pi 為 0.498；平均差值（Pi − GPU）為 −0.005，95% 區間為 −0.041 至 +0.032。這些結果尚不能證明兩者的答案品質相同。

在另一組對檢索敏感的 24 道題目中，Base+RAG 得分 0.779，閉卷 Base 為 0.325（平均增加 +0.454）。完全正確結果的 Holm 校正檢定為 p = 0.0625，未達 0.05 門檻。在預先分類為計算器支援的 24 道題目中，Base+Tools 的平均分數比 Base+RAG 高 +1.000。兩種受測 SFT 方法均未超越對應的 Base 配置。

評分先由 AI 依評分標準協助進行，再由作者審閱，並未經過獨立盲測。裝置測試與個別網頁示範的結果分開呈現。研究尚未評估學習成效、易用性或整個網頁系統的可靠性；來源與計算過程有助於核對答案，但不能保證答案正確。

論文摘要

通用語言模型助手未必能自然契合特定課程。我們提出一個以 Raspberry Pi 5 為目標裝置的平台，結合小型 Qwen3-1.7B 模型、以課程資料為依據的檢索、確定性計算，以及呈現答案、證據和工具執行情況的網頁介面。平台可依個別課程需求設定；本研究評估系統品質與邊緣部署，而非學習成效。GPU 加速評估以 96 道課程題目比較七種配置，涵蓋閉卷生成、檢索增強生成（RAG）、Calculator 執行與兩種監督式微調（SFT）方法。另以 24 道題目比較 Base 與 Base+RAG。Base + Tool-Augmented RAG 在 0–1 評分規準中取得最高平均分數 0.777。檢索提升了對來源敏感題目的平均作答品質；確定性 Calculator 執行在預先分類為支援的 24 題中帶來最明顯的增益。兩種 SFT 方法均未顯示優於對應 Base 配置的改善。96 題配對 Base 比較未檢出具方向性的 GPU–Pi 分數差異；Pi 執行相同量化模型檔案時較慢。
