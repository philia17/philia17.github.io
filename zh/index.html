機器人與感知

機器人與電梯互動

讓機器人
讀懂電梯。

辨識按鈕是一個問題；選對目標、在三維空間中定位並安全接近，則是另一個問題。本項目透過分階段、帶保護機制的流程連接這些步驟。

RGB-D · OpenCV · 校準 · 機械臂

我的貢獻：在合作研究中負責分階段感知、RGB-D 定位、校準，以及具保護機制的機械臂整合。

展開項目筆記 +

流程整合按鈕偵測、HOG+SVM 分類、語意目標選擇、RGB-D 定位、校準，以及具保護機制的機械臂互動。

評估：在 379 張標註裁切圖上取得 0.9963 的 macro-F1；離線請求層級的目標選擇準確率為 85.1%。兩次定性展示與可泛化部署的證據分開看待。

02

邊緣智慧

Raspberry Pi 5 工程助手

小型裝置。
可追溯的答案。

結合小型語言模型、課程資料檢索與計算工具，讓答案緊扣產生它的依據。

Python · Qwen3-1.7B · RAG · Raspberry Pi 5

我的貢獻：量化模型部署、檢索與計算工具、可檢視的網頁操作流程，以及配置比較。

展開項目筆記 +

以 4-bit Qwen3-1.7B 部署結合檢索與確定性計算工具。網頁原型將生成答案、檢索來源和工具輸出分開呈現。

評估：以離線 GPU 參考環境，對 96 道 EEE 題目比較七種配置。Pi 5 CPU 的觀察結果另行報告，兩者使用相同量化模型檔案；參考環境的分數並非 Pi 裝置的結果。

03

人機互動

Bangbang V2

讓人始終
參與決策。

為遠端化身機器人提供臉部與雙語語音線索。開發 Raspberry Pi 5 視覺路徑，同時由操作員保留最終決策權。

MediaPipe · ONNX · 邊緣視覺 · 遙操作

我的貢獻：協作遙操作系統中的臉部感知流程與 Pi 5 視覺整合。

展開項目筆記 +

雙 Pi 遙操作系統結合 MediaPipe FaceMesh 前端、互補的 CNN 與可解釋 FACS/AU 路徑、雙語語音，以及瀏覽器介面。

AI 輸出僅作建議，最終決策責任仍由人類操作員承擔。

兩篇不同的會議論文研究同一平台：臉部感知與雙語語音（HRFEST 論文 230），以及人在迴路中的邊緣／雲端 LLM 決策支援（IHCI 論文 99）。

03 / 關於我

學著看見
完整的系統。

葉嗣恒 / Siheng Ye

我的起點是電氣與電子工程。接下來想探索的問題，關乎機器人、控制，以及能部署在機器身邊的智慧。

我正在寧波諾丁漢大學修讀榮譽工學士學位，預計於 2027 年 7 月畢業，並準備在嵌入式系統、控制與自動化、資訊物理系統及邊緣 AI 等方向繼續深造。

目前的畢業設計以模擬研究 PMSM 預測轉矩控制中的數位延遲補償與預測穩健性。研究仍具探索性，硬體驗證留待後續進行。

在這些項目中，我關注哪些結果可以量測、哪些過程可以解釋，以及人應在哪些環節保有控制權。

探索文字，也探索世界。工程之外，我喜歡閱讀、學習語言與旅行。

我也在尋找嵌入式系統、機器人、控制、電子測試及應用 AI 方向的實習。學期中可協商每週在寧波諾丁漢大學附近到場 2–3 次，具體時數配合課表安排。
