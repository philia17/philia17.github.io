機器人與感知

機器人與電梯互動

讓機器人
讀懂電梯。

從辨識按鈕，到選對目標、確認三維位置，再安全地接近按鈕，每一步都有不同的挑戰。這個項目將它們串成分階段的操作流程，並加入保護機制。

RGB-D · OpenCV · 校準 · 機械臂

我的貢獻：參與分階段感知、RGB-D 定位與校準，並整合機械臂及其操作保護機制。

展開項目筆記 +

流程整合按鈕偵測、HOG+SVM 分類、語意目標選擇、RGB-D 定位、校準，以及具保護機制的機械臂互動。

評估：在 379 張已標註的按鈕裁切圖上，macro-F1 達 0.9963；離線目標選擇測試中，85.1% 的請求選對了目標。另有兩次實體示範，但尚不足以證明系統可在更廣泛的場景中可靠運作。

02

邊緣智慧

Raspberry Pi 5 工程助手

小型裝置。
可追溯的答案。

把小型語言模型、課程資料檢索與計算工具結合，讓使用者能查閱答案的依據。

Python · Qwen3-1.7B · RAG · Raspberry Pi 5

我的貢獻：部署量化模型、整合檢索與計算工具、建立能查閱回答依據的網頁介面，並比較不同配置。

展開項目筆記 +

以 4-bit Qwen3-1.7B 模型搭配檢索與確定性計算工具。網頁介面分別呈現模型答案、檢索來源和工具輸出，方便逐項核對。

評估：在離線 GPU 環境中，以 96 道 EEE 題目比較七種配置。Pi 5 CPU 使用相同的量化模型檔案，測試結果另外列出；GPU 上的分數不能視為 Pi 的實測結果。

03

人機互動

Bangbang V2

讓人始終
參與決策。

透過臉部動作與雙語語音，為遠端化身機器人的操作員提供參考。我的工作是開發 Raspberry Pi 5 視覺處理流程，最終決策仍由操作員作出。

MediaPipe · ONNX · 邊緣視覺 · 遙操作

我的貢獻：開發臉部感知流程，並整合至團隊遙操作系統的 Pi 5 平台。

展開項目筆記 +

雙 Pi 遙操作系統結合 MediaPipe FaceMesh 前端、互補的 CNN 與可解釋 FACS/AU 路徑、雙語語音，以及瀏覽器介面。

AI 輸出僅作建議，最終決策責任仍由人類操作員承擔。

同一平台衍生出兩篇會議論文，分別探討臉部感知與雙語語音（HRFEST 論文 230），以及由人參與決策的邊緣／雲端 LLM 輔助系統（IHCI 論文 99）。

03 / 關於我

學著看見
完整的系統。

葉嗣恒 / Siheng Ye

我從電氣與電子工程出發，希望繼續探索機器人、控制，以及能直接在裝置上運作的智慧系統。

我正在寧波諾丁漢大學修讀榮譽工學士學位，預計於 2027 年 7 月畢業，並準備在嵌入式系統、控制與自動化、資訊物理系統及邊緣 AI 等方向繼續深造。

目前的畢業設計透過模擬，研究 PMSM 預測轉矩控制中的數位延遲補償與預測穩健性。這項研究仍在探索階段，尚未進行硬體驗證。

做這些項目時，我常問自己：哪些結果能量測？哪些過程能說清楚？又有哪些決定應該留給人來做？

探索文字，也探索世界。工程之外，我喜歡閱讀、學習語言與旅行。

我也在尋找嵌入式系統、機器人、控制、電子測試或應用 AI 方向的實習。學期中可商議每週在寧波諾丁漢大學附近到場 2–3 次，實際時數需配合課表。
