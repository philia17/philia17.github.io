01

로보틱스와 인식

로봇의 엘리베이터 조작

로봇이 엘리베이터를
읽으려면.

버튼을 인식한 뒤에는 원하는 버튼을 선택하고, 3차원 위치를 찾고, 안전하게 접근해야 합니다. 이 프로젝트는 각 단계를 안전장치를 갖춘 하나의 흐름으로 연결합니다.

RGB-D · OpenCV · 보정 · 로봇 암

담당한 부분 — 공동 연구의 단계별 인식, RGB-D 기반 위치 추정, 보정, 안전장치를 포함한 로봇 암 통합.

프로젝트 노트 펼치기 +

버튼 검출, HOG+SVM 분류, 의미 기반 목표 선택, RGB-D 위치 추정, 보정, 안전장치를 갖춘 로봇 암 조작을 하나의 처리 흐름으로 통합했습니다.

평가 결과 — 라벨이 있는 버튼 잘라내기 이미지 379장에서 매크로 F1은 0.9963, 오프라인 요청 단위의 목표 선택 정확도는 85.1%였습니다. 정성적 시연 2건은 여러 환경에 적용할 수 있다는 검증과 구분합니다.

02

엣지 AI

Raspberry Pi 5 공학 학습 도우미

작은 컴퓨터에서
근거를 확인할 수 있는 답변을.

소형 언어 모델에 수업 자료 검색과 계산 도구를 결합했습니다. 답변과 함께 답변이 나온 근거를 바로 확인할 수 있도록 하는 것이 목표입니다.

Python · Qwen3-1.7B · RAG · Raspberry Pi 5

담당한 부분 — 양자화 모델 배포, 검색·계산 도구, 처리 근거를 확인할 수 있는 웹 인터페이스, 구성 간 비교.

프로젝트 노트 펼치기 +

4비트로 양자화한 Qwen3-1.7B에 자료 검색과 결정론적 계산 도구를 결합했습니다. 웹 시제품은 생성된 답변, 검색된 출처, 도구 출력을 구분해 보여줍니다.

평가 결과 — 전기전자공학 96문항으로 GPU 기준 오프라인 평가에서 7개 구성을 비교했습니다. 같은 양자화 모델을 사용한 Pi 5 CPU 관찰 결과는 별도로 보고합니다. 기준 점수는 GPU에서 측정했습니다.

03

인간–로봇 상호작용

Bangbang V2

최종 판단은
사람이 내립니다.

아바타 로봇의 원격 조작을 돕는 표정 인식과 이중 언어 음성 인식입니다. 조작자가 최종 결정을 내리는 구조에서 Raspberry Pi 5의 영상 인식 경로를 개발했습니다.

MediaPipe · ONNX · 엣지 영상 인식 · 원격 조작

담당한 부분 — 공동 개발한 원격 조작 시스템의 표정 인식 파이프라인과 Pi 5 영상 인식 통합.

프로젝트 노트 펼치기 +

Pi 2대를 사용하는 원격 조작 시스템은 MediaPipe FaceMesh 프런트엔드, 상호 보완적인 CNN과 해석 가능한 FACS/AU 인식 경로, 이중 언어 음성 인식, 브라우저 인터페이스를 결합합니다.

AI 출력은 판단을 돕는 참고 정보입니다. 최종 결정의 책임은 조작자에게 있습니다.

공통 플랫폼을 다룬 학회 논문은 2편입니다. 표정 인식과 이중 언어 음성 인식은 HRFEST 논문 230에서, 사람이 판단에 참여하는 엣지·클라우드 LLM 의사결정 지원은 IHCI 논문 99에서 다룹니다.

03 / 소개

시스템 전체를
보는 법을 배우다.

葉嗣恒 / Siheng Ye

전기전자공학을 출발점으로 로보틱스와 제어, 기계 가까이에서 구동할 수 있는 AI를 탐구하고 있습니다.

노팅엄대학교 닝보 중국 캠퍼스에서 BEng (Hons) 과정을 이수하고 있으며 2027년 7월 졸업 예정입니다. 임베디드 시스템, 제어 및 자동화, 사이버물리시스템, 엣지 AI 분야의 대학원 진학을 준비하고 있습니다.

졸업 연구에서는 PMSM 예측 토크 제어의 디지털 지연 보상과 예측 강건성을 시뮬레이션으로 살펴보고 있습니다. 탐색 단계의 연구이며 하드웨어 검증은 향후 과제입니다.

어떤 프로젝트에서든 무엇을 측정할 수 있는지, 무엇을 설명할 수 있는지, 사람이 어느 단계에서 제어권을 유지해야 하는지를 중요하게 생각합니다.

언어와 세상을 탐구합니다. 공학 외에는 독서, 언어 공부, 여행을 즐깁니다.

임베디드 시스템, 로보틱스, 제어, 전자기기 시험, 응용 AI 분야 인턴십을 찾고 있습니다. 학기 중에는 수업 시간에 맞춰 UNNC 인근에서 주 2~3회 출근을 협의할 수 있습니다.
