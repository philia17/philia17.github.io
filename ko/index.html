로봇공학과 인식

로봇의 엘리베이터 조작

로봇은 엘리베이터 버튼을
어떻게 읽을까?

버튼을 알아보는 것만으로는 부족합니다. 요청한 버튼을 고르고 3차원 위치를 구한 뒤 안전하게 접근해야 합니다. 이 프로젝트에서는 각 단계를 안전장치와 함께 하나의 흐름으로 연결했습니다.

RGB-D · OpenCV · 캘리브레이션 · 로봇 팔

제가 맡은 일 · 공동 연구에서 단계별 인식, RGB-D 위치 추정과 캘리브레이션, 안전장치를 갖춘 로봇 팔 연동을 맡았습니다.

프로젝트 노트 보기 +

버튼을 검출해 HOG+SVM으로 분류한 뒤, 버튼의 의미를 바탕으로 대상을 선택합니다. RGB-D로 위치를 추정하고 좌표계를 보정해 안전장치를 갖춘 로봇 팔 조작으로 이어집니다.

평가 결과 · 라벨을 붙인 버튼 영역 이미지 379장에서 매크로 F1은 0.9963이었습니다. 오프라인에서 요청별로 대상 버튼을 고른 정확도는 85.1%였습니다. 정성적 시연 2건은 여러 환경에서의 작동을 검증한 결과와 구분합니다.

02

엣지 AI

Raspberry Pi 5 공학 학습 도우미

작은 컴퓨터가 내놓는 답변,
그 근거까지 확인할 수 있게.

소형 언어 모델에 수업 자료 검색과 계산 도구를 더했습니다. 답변을 읽으면서 어떤 자료나 계산을 바탕으로 했는지도 바로 확인할 수 있게 하는 것이 목표입니다.

Python · Qwen3-1.7B · RAG · Raspberry Pi 5

제가 맡은 일 · 양자화 모델을 배포하고 검색·계산 도구와 근거를 확인할 수 있는 웹 화면을 구현했습니다. 시스템 구성별 성능도 비교했습니다.

프로젝트 노트 보기 +

4비트 양자화 모델 Qwen3-1.7B에 자료 검색과 결정론적 계산 도구를 결합했습니다. 웹 시제품에서는 생성한 답변, 찾아낸 자료, 도구의 실행 결과를 따로 볼 수 있습니다.

평가 결과 · 전기전자공학 96문항을 사용해 GPU 기준 환경에서 7개 구성을 오프라인으로 비교했습니다. 같은 양자화 모델을 Pi 5 CPU에서 실행해 관찰한 결과는 별도로 제시합니다. 기준 점수는 GPU에서 측정했습니다.

03

인간–로봇 상호작용

Bangbang V2

최종 판단은
사람이 내립니다.

원격 조작 아바타 로봇은 표정과 두 언어의 음성 입력을 활용합니다. 저는 Raspberry Pi 5의 영상 인식 기능을 개발했습니다. 최종 판단은 조작자가 내립니다.

MediaPipe · ONNX · 엣지 영상 인식 · 원격 조작

제가 맡은 일 · 공동 개발한 원격 조작 시스템에서 표정 인식 과정을 구현하고 Pi 5에 통합했습니다.

프로젝트 노트 보기 +

Pi 2대를 쓰는 원격 조작 시스템입니다. MediaPipe FaceMesh를 공통 입력 처리에 사용하고, 서로 보완하는 CNN과 해석 가능한 FACS/AU 인식 방식을 적용했습니다. 두 언어의 음성 인식과 브라우저 조작 화면도 연동했습니다.

AI는 판단에 참고할 정보를 제시합니다. 최종 결정과 그 책임은 조작자에게 있습니다.

같은 플랫폼을 다룬 학회 논문은 2편입니다. HRFEST 논문 230은 표정 인식과 두 언어의 음성 인식을, IHCI 논문 99는 조작자의 판단을 돕는 엣지·클라우드 LLM을 다룹니다.

03 / 소개

시스템 전체를
보는 법을 배우다.

葉嗣恒 / Siheng Ye

전기전자공학에서 출발해 로봇공학과 제어를 공부하고, 기계가 쓰이는 현장에서 구동할 수 있는 AI를 탐구하고 있습니다.

노팅엄대학교 중국 닝보 캠퍼스에서 BEng (Hons) 과정을 밟고 있으며, 2027년 7월 졸업 예정입니다. 임베디드 시스템, 제어·자동화, 사이버물리시스템, 엣지 AI 분야로 대학원 진학을 준비하고 있습니다.

졸업 연구에서는 PMSM의 예측 토크 제어에서 디지털 지연을 보상하는 방법과 예측의 강건성을 시뮬레이션으로 살펴봅니다. 현재는 탐색 단계로, 실제 하드웨어 검증은 아직 진행하지 않았습니다.

프로젝트마다 무엇을 측정하고 설명할 수 있는지, 그리고 어느 단계에서 사람이 제어권을 가져야 하는지를 중요하게 생각합니다.

언어와 새로운 세계에 관심이 많습니다. 공학 밖에서는 독서, 외국어 공부, 여행을 즐깁니다.

임베디드 시스템, 로봇공학, 제어, 전자기기 시험, 응용 AI 분야의 인턴십을 찾고 있습니다. 학기 중에는 수업 시간에 맞춰 UNNC 인근에서 주 2~3회 현장 근무를 협의할 수 있습니다.
