영상 인식 플랫폼Raspberry Pi 5

MediaPipe 얼굴 랜드마크를 학습된 CNN/ONNX 경로와 해석 가능한 얼굴 행동 단위 경로로 처리합니다.

주요 담당표정 인식

팀 시스템에서 영상 인식 파이프라인 구현과 Raspberry Pi 통합을 담당했습니다.

최종 결정권조작자

관찰 가능한 얼굴 움직임과 응답 후보를 제시해 조작자의 판단을 돕습니다.

프로젝트 개요

Bangbang은 공동 개발한 원격 조작 아바타 로봇 플랫폼입니다. 조작자는 표정과 이중 언어 음성 단서를 바탕으로 상호작용을 확인하고 응답 방식을 선택합니다.

이 프로젝트에서 인식 연구(HRFEST 논문 230)와 조작자 지원 연구(IHCI 논문 99)라는 학회 논문 2편이 나왔습니다. 제출한 FURP 2026 포스터는 두 연구를 함께 소개합니다.

담당한 부분

표정 인식 파イ프라인과 Raspberry Pi 5 통합을 주로 담당했습니다. MediaPipe 얼굴 랜드마크의 공통 프런트엔드, 학습된 CNN/ONNX 경로, 해석 가능한 얼굴 행동 단위 경로를 구현했습니다.

다른 팀원들은 음성, 조작자 인터페이스, 원격 조작 구성요소를 담당했습니다. 인식 출력은 관찰 가능한 움직임을 나타냅니다. 내적 감정이나 임상적 상태의 측정값으로서 타당성은 검증되지 않았습니다.

시제품과 평가 범위

공개 버전에는 얼굴 랜드마크 및 행동 단위 처리, 감정 인식 모델 정의, 학습·내보내기 스크립트, Raspberry Pi 영상 인식 예제가 포함됩니다. 데이터셋과 학습된 모델 파일은 포함하지 않았습니다.

초기 고정형 음성·영상 인식 브랜치는 Vosk와 영어 예시 어휘를 사용합니다. 이후의 영상 인식 작업과 별도로 보존하며, 팀 연구에서 설명하는 이중 언어 음성 인식이나 원격 조작 시스템 전체를 재현하지는 않습니다.

논문 99의 발표 자료에는 로컬 및 클라우드 AI 지원, 이중 언어 입력, 응답 제안을 검토하는 브라우저 인터페이스가 나옵니다. 중국어 음성 인식에는 클라우드 서비스를 사용합니다. 처리 시간은 프롬프트와 설정이 서로 다른 개발 과정의 관찰값이며, 통제된 조건에서 모델 순위를 매긴 결과는 아닙니다.

기능 확인과 시연은 시제품의 개별 기능을 보여줍니다. 전체 처리의 신뢰성, 감정 해석의 정확성, 조작자 업무 부담 감소, 사용자 편익은 추가 평가가 필요합니다.
