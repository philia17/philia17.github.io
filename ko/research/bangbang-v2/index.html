제가 맡은 일표정 인식

팀이 개발한 시스템에서 영상 인식 기능을 구현하고 Raspberry Pi에 통합했습니다.

최종 결정권조작자

관찰할 수 있는 얼굴 움직임과 응답 후보를 조작자에게 보여줘 판단을 돕습니다.

프로젝트 개요

Bangbang은 팀에서 개발한 원격 조작 아바타 로봇 플랫폼입니다. 조작자는 표정과 두 언어의 음성 입력을 참고해 상황을 살펴보고 어떻게 응답할지 결정합니다.

이 프로젝트에서 인식 연구(HRFEST 논문 230)와 조작자 지원 연구(IHCI 논문 99)를 다룬 학회 논문 2편이 나왔습니다. FURP 2026에 제출한 포스터에는 두 연구를 함께 담았습니다.

제가 맡은 일

저는 표정 인식 기능을 구현하고 Raspberry Pi 5에 통합하는 일을 주로 맡았습니다. MediaPipe로 공통 얼굴 특징점을 추출한 뒤, 학습한 CNN/ONNX 모델과 해석 가능한 얼굴 행동 단위 방식으로 처리하도록 구현했습니다.

음성 처리, 조작 화면, 원격 조작 기능은 다른 팀원들이 맡았습니다. 인식 결과는 겉으로 드러나는 얼굴 움직임을 나타냅니다. 감정 상태나 임상적 상태를 측정할 수 있는지는 검증하지 않았습니다.

시제품과 평가 범위

공개 버전에는 얼굴 특징점과 행동 단위를 처리하는 코드, 감정 인식 모델 정의, 학습·내보내기 스크립트, Raspberry Pi 영상 인식 예제를 담았습니다. 데이터셋과 학습된 모델 파일은 포함하지 않았습니다.

초기 고정형 음성·영상 인식 브랜치는 Vosk에서 영어 예시 단어를 인식합니다. 이후 개발한 영상 인식 코드와는 별도로 보관합니다. 이 브랜치로는 팀 연구에 나온 두 언어의 음성 인식 기능이나 원격 조작 시스템 전체를 재현할 수 없습니다.

논문 99의 발표 자료에는 로컬·클라우드 AI 지원, 두 언어의 입력, 응답 제안을 검토하는 브라우저 화면이 나옵니다. 중국어 음성 인식에는 클라우드 서비스를 사용합니다. 처리 시간은 프롬프트와 설정을 바꿔 가며 개발 중에 관찰한 값으로, 조건을 통제해 모델의 성능 순위를 매긴 결과는 아닙니다.

기능 점검과 시연으로 시제품의 일부 기능을 확인했습니다. 전체 시스템의 신뢰성, 감정 해석의 정확성, 조작자 부담 감소와 사용자에게 실질적인 도움이 되는지는 추가 평가가 필요합니다.
