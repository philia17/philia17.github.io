Raspberry Pi 5 공학 학습 도우미

참조 자료와 계산 과정을 확인할 수 있는 수업용 학습 도우미입니다.

Siheng Ye · Xiaotong Li · Chang Qi · Linfei Yin · Yaokun Zhang · Ian Pratt

프로젝트 개요

소형 언어 모델은 잘못된 자료를 참조하거나 계산을 틀려도 매끄러운 답변을 생성할 수 있습니다. 이 시제품은 4비트로 양자화한 Qwen3-1.7B에 수업 자료 검색과 결정론적 계산 도구를 결합했습니다.

Ask는 답변과 함께 출처 또는 계산 과정을 보여줍니다. Quiz는 응답을 제출하면 피드백과 근거 자료를 보여줍니다. Raspberry Pi 5를 대상으로 한 플랫폼이며, 평가 결과는 구성요소와 기기를 구분해 제시합니다.

담당한 부분

팀 프로젝트에서 엣지 시제품 구현을 주도했습니다. 검색·계산 도구를 통합하고, 처리 근거를 확인할 수 있는 Ask/Quiz 흐름을 구축했으며, 시스템 구성을 비교했습니다.

결과와 평가 범위

주 평가에서는 전기전자공학 96문항으로 오프라인 GPU 기준 환경에서 7개 구성을 비교했습니다. 표에는 0–1 척도의 루브릭 평균 점수와 연구의 완전 정답 기준을 충족한 응답 수를 제시합니다.

오프라인 GPU 기준 평가 · 전기전자공학 96문항
구성루브릭 평균 점수완전 정답
Base(외부 자료 미참조)0.50328 / 96
Base + RAG0.55534 / 96
Base + Tools0.77754 / 96

확장 SFT(외부 자료 미참조)0.40821 / 96
확장 SFT + Tools0.58439 / 96

RAG는 검색 증강 생성, SFT는 지도 미세조정입니다. 루브릭 점수는 정확도 백분율을 뜻하지 않습니다. Base + Tools는 도구를 추가한 RAG 구성으로, 지원하는 계산에는 결정론적 Calculator를 사용하고 그 밖의 요청에는 검색을 사용합니다. 강조한 GPU의 Base + Tools와 Pi의 외부 자료 미참조 Base는 서로 다른 구성을 평가한 결과이므로 동일 조건의 하드웨어 비교에는 사용할 수 없습니다.

외부 자료를 참조하지 않는 Base를 같은 조건에서 비교한 별도 평가에서는 두 기기에서 동일한 양자화 모델 파일과 96문항을 사용했습니다. 평균은 GPU 0.503, Pi 0.498이었습니다. 평균 차이(Pi − GPU)는 −0.005였고 95% 구간은 −0.041에서 +0.032였습니다. 답변 품질이 동등하다는 점은 입증하지 못했습니다.

검색의 영향을 많이 받는 별도 24문항에서 Base+RAG는 0.779, 외부 자료 미참조 Base는 0.325였습니다(평균 변화 +0.454). 완전 정답에 대한 Holm 보정 검정의 p = 0.0625는 0.05 기준을 충족하지 못했습니다. Calculator가 지원하는 것으로 사전 분류한 24문항에서 Base+Tools는 Base+RAG보다 평균 +1.000점 높았습니다. 평가한 두 SFT 방법 모두 대응하는 Base 구성을 앞서지 못했습니다.

AI 보조 루브릭 채점 후 저자가 검토하는 방식으로 평가했으며, 독립적인 맹검 검증은 수행하지 않았습니다. 기기에서의 관찰과 일부 웹 시연은 서로 다른 근거입니다. 학습 효과, 사용성, 웹 시스템 전체의 신뢰성은 검증하지 않았습니다. 출처나 계산 과정은 검토에 도움이 되지만, 그 표시만으로 답변이 정확하다고 볼 수는 없습니다.

논문 초록

범용 언어 모델 도우미를 특정 과목에 맞추려면 별도의 조정이 필요하다. 본 연구는 소형 Qwen3-1.7B 모델, 수업 자료 기반 검색, 결정론적 계산, 그리고 답변과 근거 및 도구 실행 내용을 보여주는 웹 포털을 결합한 Raspberry Pi 5용 플랫폼을 제시한다. 개별 과목 요건에 맞춰 구성할 수 있으며, 평가 대상은 시스템 품질과 엣지 배포다. 학습 성과는 평가하지 않았다. GPU 가속 평가에서는 외부 자료 미참조 생성, 검색 증강 생성(RAG), Calculator 실행, 두 가지 지도 미세조정(SFT) 방법을 포함한 7개 구성을 수업 관련 96문항에서 비교했다. 별도 24문항에서는 Base와 Base+RAG를 비교했다. Base + Tool-Augmented RAG는 0–1 척도에서 가장 높은 루브릭 평균 점수 0.777을 기록했다. 검색은 출처가 중요한 문항에서 평균 품질을 높였고, 지원 대상으로 사전 분류한 24문항에서는 결정론적 Calculator 실행이 가장 뚜렷한 향상을 보였다. 두 SFT 방법 모두 대응하는 Base 구성보다 개선되지 않았다. 동일한 96문항을 사용한 대응 Base 비교에서는 GPU와 Pi 점수 차이의 방향성이 검출되지 않았다. Pi에서 동일한 양자화 모델을 실행하는 데는 더 긴 시간이 걸렸다.
