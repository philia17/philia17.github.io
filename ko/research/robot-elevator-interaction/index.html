로봇의 엘리베이터 조작

엘리베이터 조작부를 인식하고 조작자가 요청한 버튼을 누릅니다.

Siheng Ye · Zejing Tong · Suiyi Zhang · David Chieng

조작자의 지시에 따라 버튼을 작동시킨 정성적 시연입니다. 반복 시험의 성공률은 측정하지 않았습니다.

프로젝트 개요

기존 엘리베이터 패널을 사용하면 제조사별 인터페이스 없이 조작할 수 있습니다. 이를 위해 버튼을 찾고, 표기를 해석하고, 요청된 버튼을 선택해 로봇 암 좌표계로 변환하는 여러 단계가 필요합니다.

시제품은 Jetson AGX Orin에서 동작하며 RGB-D 카메라, 손목 카메라, 로봇 암을 사용합니다. 조작자가 카트의 위치를 잡고 버튼 조작을 한 번씩 요청합니다. 시연 중 카트는 정지해 있습니다.

담당한 부분

패널의 단계별 인식과 목표 선택, RGB-D 위치 추정 및 보정, 안전장치를 갖춘 로봇 암 조작과의 통합을 담당했습니다.

이 시스템은 Zejing Tong, Suiyi Zhang, David Chieng과 함께 진행한 공동 연구입니다.

결과와 평가 범위

인식 벤치마크, 실행 중 관찰, 실물 시연은 각각 다른 항목을 평가합니다. 저장 이미지의 목표 선택 결과는 실시간 인식부터 버튼 조작까지 전체 과정의 성공률을 측정한 값이 아닙니다.

99.8%는 요청 필터링 비율입니다. 인식 정확도와 버튼 누름 성공률은 이 수치의 평가 대상에 해당하지 않습니다. 작동 사례 2건으로 여러 엘리베이터에서의 반복 가능성을 입증할 수 없으며, 누름 힘과 위치 정확도는 정량화하지 않았습니다.

두 녹화 모두 로봇 암이 버튼에 접촉하고 버튼에 불이 들어온 뒤 암이 물러나는 모습을 보여줍니다. 다음 단계는 다양한 패널에서 실시간 인식부터 버튼 누름까지 반복 평가하고 결과 판정과 복구 절차를 명확히 하는 것입니다.

논문 초록

기존 로봇용 엘리베이터 인터페이스는 제조사별 개조가 필요해 비용이 들고 확장하기 어렵다. 기존 조작 패널을 직접 조작하는 방식은 인프라 개조에 의존하지 않는 대안이지만, 패널 배치, 조명, 반사, 표기 관행이 달라도 로봇이 조작부를 안정적으로 인식하고 해석해 작동시켜야 한다. 본 연구는 과업별 버튼 검출, 전용 목표 인식, 시각·언어 기반 의미 이해, 신뢰도 기반 거부, 의미 상태 유지, 비동기 처리, 실물 버튼 작동을 통합한 엣지 기반 인식–동작 시제품을 제시한다. 인식 성능과 정지 이미지 기반 목표 선택, 실행 중 동작을 평가했으며 정성적 버튼 작동 시연 2건을 통해 실물 작동을 살펴봤다. 6개 건물에서 얻은 정지 RGB 이미지 112장으로 구성한 목표 선택 요청 475건 중 404건에서 의도한 버튼을 선택해 정확도 85.1%를 기록했다. 사람이 Open/Close/Other로 주석을 단 버튼 잘라내기 이미지 379장의 별도 벤치마크에서 HOG+SVM 분류기의 매크로 F1은 0.9963이었다. 207초 실행 평가에서는 중복된 후보 단위 의미 분석 요청의 99.8%를 걸러냈고, 라벨 전환, 깜박임, 비정상 종료, 카메라 중단은 관찰되지 않았다. 조작자가 시작한 실물 버튼 작동 시연 2건 모두 로봇 암이 선택한 버튼을 작동시키고 물러난 뒤 대기 상태로 돌아갔다. 이 결과는 강건하고 오프라인에서 실시간으로 동작하는 엣지 기반 로봇–엘리베이터 상호작용 시스템의 실용적 시사점과 설계 고려 사항을 제시한다.
